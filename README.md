## Featured Project

### 🩺 PULSOAPP / Saúde Fácil UBS

A digital health concept designed to help citizens interact with public health units in a simple, accessible and human-centered way.

**Main goals:**

- Make appointment requests easier;
- Reduce queues and missed appointments;
- Help citizens track requests, exams and health unit messages;
- Support UBS teams with better organization, dashboards and care flow visibility;
- Use simple, popular language so people actually understand and enjoy using the app.

> The app is designed to complement official public health systems and respect data privacy, accessibility and public service workflows.
